Data We Collect

Depending on how you use dreamhubb, we may process:

  • Account data, such as email address, username, and login-related data.
  • Profile data, such as avatar, bio, coarse profile location, and preferences.
  • Registration and account information, such as date of birth and gender.
  • User content, such as posts, titles, descriptions, bios, comments/contributions, and uploaded images.
  • Purchase-related information, such as transaction/purchase metadata and Token-related purchase history where applicable.
  • Limited technical and security information, such as server-side operational/security logs and information used for abuse prevention and rate limiting.

We do not collect GPS or precise device location. Profile location used in dreamhubb is coarse location information that you provide (for example continent, country, and city).

How We Use Data

  • To create and manage user accounts.
  • To operate profiles, posts, interactions, and related social features.
  • To support moderation, abuse prevention, and service integrity.
  • To provide camera/photo upload functionality when you choose to use it.
  • To operate Token and account functionality, including related history and statistics.
  • To maintain security, troubleshoot issues, and keep the service reliable.
  • When you choose to use the Translate feature, to process the relevant post title and description or user bio to generate an on-demand translation.

Translate is user-triggered and on-demand. The original content remains the default. Translation processing is performed only to provide the translation you request.

AI-Assisted Translation

If you use Translate, dreamhubb may generate an on-demand translation of selected user-generated content.

The app does not send translation content directly from the device to OpenAI. When you request a translation, the dreamhubb backend loads the relevant content from our database and sends only the fields needed for that request:

  • for a post: title and description; and
  • for a profile/user translation: bio.

We do not send your username, user ID, email address, location, JWT/authentication tokens, or device metadata to OpenAI for translation.

OpenAI processes this limited content as our translation provider for the purpose of generating the requested translation. dreamhubb configures translation requests to the OpenAI Responses API with store: false, which disables storage of the generated Response as application state for later retrieval. This does not necessarily eliminate all provider-side security or abuse-monitoring processing. OpenAI may retain limited API data for security and abuse-prevention purposes in accordance with its applicable API data policies. dreamhubb does not use this content for advertising or tracking.

Under OpenAI's current API data policies, API inputs and outputs are not used to train OpenAI models by default unless the API customer explicitly opts in.

Generated translations may be cached by dreamhubb for approximately 30 days to improve performance and reduce repeated external processing. The cache may include generated translation fields and source-language metadata. Cache keys may use a content hash, but the cached value may contain the translated fields themselves.

Any additional retention or processing by OpenAI is governed by OpenAI’s applicable API data policies and settings, which may change over time.

In-App Purchases and Payments

Token purchases on iOS are currently unavailable. The iOS app may still display Token-related historical or account statistics associated with your dreamhubb account.

Where web-based Token purchases are available, they may be processed using Stripe. dreamhubb does not receive or store your full payment card details. Payment providers process payment details according to their own policies.

We may store purchase or transaction metadata needed for the Token ledger, transaction verification, fraud prevention, accounting, dispute handling, or account history.
