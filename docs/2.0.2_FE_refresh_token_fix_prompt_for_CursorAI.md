# 🛠️ Fix: Auto-login po refreši (FE zostáva prihlásený)

## 🎯 Cieľ
Aktuálne sa používateľ po refreši (`Ctrl + R`) odhlási, hoci JWT token je uložený v `localStorage`.
Cieľom je opraviť inicializáciu aplikácie tak, aby `autoLogin()` z `api-call-store.ts`
bežal **hneď po štarte** a FE zostal prihlásený, pokiaľ je token platný.

## 🔍 Kontext
- Framework: **Vue 3 + Quasar + Pinia + TypeScript**
- Súbory na úpravu:
  - `src/App.vue`
  - `src/stores/api-call-store.ts`
  - (voliteľne) `src/router/index.ts` — ak existuje redirect kontrola
- Aktuálne FE:
  - správne ukladá JWT token do `localStorage`
  - vie refreshnúť token pri expirácii
  - ale po reloadnutí stránky sa reštartuje Pinia store a stratí stav `isAuthenticated`

## ⚙️ Úpravy – FIX PACK

### 1️⃣ `src/stores/api-call-store.ts`

➡️ Doplň/aktualizuj metódu `autoLogin()` takto:

    ts

    async autoLogin() {
      const token = localStorage.getItem("jwtToken");

      if (!token) {
        if (process.env.NODE_ENV === "development") {
          console.warn("⚠️ No token found in LocalStorage");
        }
        return;
      }

🔹 Token existuje – otestuj platnosť

      try {
        if (process.env.NODE_ENV === "development") {
          console.log("🔁 AutoLogin triggered, testing token validity...");
        }

        const res = await api.get("/posts"); // jednoduchý test endpoint
        if (res.status === 200) {
          if (process.env.NODE_ENV === "development") {
            console.log("✅ Auto-login successful – token valid");
          }
          return true;
        }
      } catch (err: any) {
        // Ak token neplatí → skúsi refresh interceptor
        if (err.response?.status === 401) {
          if (process.env.NODE_ENV === "development") {
            console.warn("⚠️ Token invalid, will rely on refresh interceptor...");
          }
        } else {
          console.error("🚫 Auto-login error:", err.message);
        }
      }
    }

### 2️⃣ src/App.vue

➡️ Uisti sa, že autoLogin() sa volá okamžite po mountnutí aplikácie.

Nahraď obsah -script setup- (alebo pridaj do setup()) takto:

    <script setup lang="ts">
    import { onMounted } from "vue";
    import { useApiCallStore } from "src/stores/api-call-store";

    const apiStore = useApiCallStore();

    onMounted(async () => {
      console.log("🚀 App mounted, triggering autoLogin check...");
      await apiStore.autoLogin();
    });
    </script>

💡 Toto zabezpečí, že hneď po načítaní aplikácie sa:
- overí token z localStorage,
- v prípade platnosti zostane FE prihlásený,
- a až následne sa zobrazí layout (žiadne presmerovanie na /login bez dôvodu).

### 3️⃣ (Voliteľné) src/router/index.ts

➡️ Ak Cursor nájde podmienku typu:

    if (!localStorage.getItem("jwtToken")) {
      router.push("/login");
    }

nahraď ju bezpečnejším variantom:

    import { useApiCallStore } from "src/stores/api-call-store";

    router.beforeEach(async (to, from, next) => {
      const apiStore = useApiCallStore();
      const token = localStorage.getItem("jwtToken");

      if (token) {
        await apiStore.autoLogin();
        next();
      } else {
        if (to.path !== "/login") next("/login");
        else next();
      }
    });

## 🧪 Testovanie po úprave

### ✅ Scenár A – Auto-login po refreši
- Prihlás sa (mato@example.com / secret123).
- Stlač Ctrl + R.
- Sleduj Console (DevTools):
  - „🚀 App mounted, triggering autoLogin check...“
  - „✅ Auto-login successful – token valid“
- Over, že zostávaš na /donor/posts (žiadny redirect na /login).

### ✅ Scenár B – Expired token
- Po prihlásení ručne poškodz token v LocalStorage.
- Refreshni stránku.
- Sleduj logy:
  - „⚠️ Token invalid, will rely on refresh interceptor...“
  - „✅ Token successfully refreshed“
  - Ak to prebehne → refresh flow funguje.

### ✅ Scenár C – Logout
- Zavolaj apiStore.logout().
- Skontroluj, že token sa odstránil a redirectol ťa na /login.

## 🧩 Očakávaný výsledok
- FE po štarte overí token a zostane prihlásený, ak je platný.
- Ak token expiroval → automaticky prebehne refresh.
- Ak refresh zlyhá → redirect na /login.
- Po Ctrl + R sa aplikácia už neodhlási.
