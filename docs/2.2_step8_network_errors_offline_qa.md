## Ako testovať v Chrome DevTools

### 1) Offline
- DevTools → **Network** → **Offline**
- Očakávanie:
  - zobrazí sa **OfflineBanner** (“You’re offline…”)
  - API volania skončia user-friendly toastom (bez “ERR_NETWORK”)
  - app sa nezrúti / nerozbije layout

### 2) Slow 3G (weak net)
- DevTools → Network → Throttling → **Slow 3G**
- Očakávanie:
  - feed / post detail buď dobehne neskôr, alebo ukáže bezpečnú chybu a “Retry” (tam, kde je implementované)

### 3) Timeout
- DevTools → Network → Throttling → **Custom** a nastav extrémne nízku rýchlosť
- Očakávanie:
  - po ~20s dostaneš toast “Request timed out…”

### 4) Expired token / 401
- Vymaž/poškod token v localStorage (`token`)
- Sprav request na chránený endpoint
- Očakávanie:
  - refresh sa skúsi max 1×
  - následne “Session expired. Please sign in again.” + redirect na login
  - bez logovania tokenov do konzoly

## Definition of Done (checklist)
