# ⚙️ Prompt pre CursorAI
## 🔹 Sekcia: 2.0.1 / FE ↔ BE integrácia (axios, login/register, JWT)

---

### 🎯 Cieľ
Zabezpečiť, aby vo Vue 3 + Quasar projekte **`dreamhubb-FE-main`**
bol **axios interceptor** správne nastavený tak, aby automaticky pripájal JWT token
z `localStorage.jwtToken` do každého requestu (napr. `/api/posts`).

---

### 🧩 Kontext projektu
- Framework: **Vue 3 + Quasar + Pinia + TypeScript**
- Aplikácia beží: `npm run dev` → http://localhost:9000
- Backend API: `php artisan serve` → http://127.0.0.1:8000/api
- JWT token sa ukladá do: `localStorage.jwtToken`
- Axios definícia: `/src/boot/axios.ts`
- Pinia store pre API call: `/src/stores/api-call-store.ts`

      }

#### ✅ Vytvor 2 axios inštancie

    const axiosInstance = axios.create({
      baseURL: "http://127.0.0.1:8000/api",
      headers: {
        "Content-Type": "application/json",
        Accept: "application/json",
      },
    });

    const api = axios.create({
      baseURL: "http://127.0.0.1:8000/api",
      headers: {
        "Content-Type": "application/json",
        Accept: "application/json",
      },
    });

#### ✅ Funkcia, ktorá pripojí interceptor k danej inštancii

    const attachInterceptor = (instance: AxiosInstance) => {
      instance.interceptors.request.use(
        (config) => {
          const token = localStorage.getItem("jwtToken");
          if (token) {
            config.headers.Authorization = `Bearer ${token}`;
            console.log("✅ Token attached:", token.substring(0, 25) + "...");
          } else {
            console.warn("⚠️ No token found in LocalStorage");
          }
          return config;
        },
        (error) => Promise.reject(error)
      );
    };

#### ✅ Pripoj interceptor na obe inštancie

    attachInterceptor(axiosInstance);
    attachInterceptor(api);

#### ✅ Zaregistruj do Vue

    export default boot(({ app }) => {
      app.config.globalProperties.$axios = axiosInstance;
      app.config.globalProperties.$api = api;
    });

    export { api };

#### 2️⃣ Úprava /src/stores/api-call-store.ts

Cursor, pridaj testovací request po logine – len na overenie interceptoru:

    import { defineStore } from "pinia";
    import { api } from "boot/axios";

    export const useApiCallStore = defineStore("apiCall", {
      state: () => ({}),

      actions: {
        login(data: { email: string; password: string }) {
          return api.post("/login", data).then(async (res) => {
            const token =
              res.data?.authorization?.token ||
              res.data?.access_token ||
              res.data?.token;

            if (token) {
              localStorage.setItem("jwtToken", token);
              console.log("🔑 JWT uložený:", token.substring(0, 25) + "...");
            }

            // 🧪 Test interceptoru
            try {
              const test = await api.get("/posts");
              console.log("🧪 Test /posts status:", test.status);
            } catch (err) {
              console.error("🚫 Test /posts failed:", err);
            }

            return res;
          });
        },

        getPosts() {
          return api.get("/posts");
        },
      },
    });
