# 🩹 Bugfix: Auto-login stále nefunguje po refreši stránky (Ctrl + R)

## 🧭 Kontext
Po predošlej implementácii „auto-login“ systému (2.0.2) sa používateľ **stále odhlasuje po refreši stránky (Ctrl + R)**.
V `localStorage` síce ostáva uložený JWT token, ale aplikácia ho **nevaliduje dostatočne skoro**,
alebo **store sa reštartuje skôr, než sa autoLogin() stihne spustiť**.

## 🎯 Cieľ
Opraviť flow tak, aby používateľ:
- zostal **prihlásený aj po reloadnutí stránky**,
- FE pri štarte **automaticky overil token**,
- **nepresmeroval** na `/login`, pokiaľ je token platný,
- a ak token nie je platný, aby FE **spustil refresh** alebo redirect.

## ⚙️ Požadované opravy (Cursor vykoná)

### 1️⃣ `src/stores/api-call-store.ts`
- Pridaj `isAuthenticated: boolean` do `state()`
- Po úspešnom prihlásení → nastav `isAuthenticated = true`
- Po `logout()` → `isAuthenticated = false`
- Upraviť `autoLogin()`:

      ts

      async autoLogin() {
        const token = localStorage.getItem("jwtToken");
        if (!token) {
          console.warn("⚠️ No token found, skipping autoLogin");
          this.isAuthenticated = false;
          return false;
        }

        try {
          const res = await api.get("/posts");
          if (res.status === 200) {
            console.log("✅ Auto-login successful – token valid");
            this.isAuthenticated = true;
            return true;
          }
        } catch (err) {
          if (err.response?.status === 401) {
            console.warn("⚠️ Token invalid, trying refresh...");
            try {
              const refresh = await api.post("/refresh");
              const newToken = refresh.data?.authorization?.token || refresh.data?.access_token;
              if (newToken) {
                localStorage.setItem("jwtToken", newToken);
                console.log("🔁 Token refreshed successfully");
                this.isAuthenticated = true;
                return true;
              }
            } catch (refreshErr) {
              console.error("🚫 Refresh failed:", refreshErr.message);
              this.logout();
            }
          }
        }
      }

### 2️⃣ src/App.vue
- Pridaj oneskorené spustenie autoLogin() pred renderom layoutu.
- Ak token existuje → počkaj na výsledok autoLogin() pred tým, než appka načíta route.
- Kód:

      <script setup lang="ts">
      import { onMounted } from "vue";
      import { useApiCallStore } from "src/stores/api-call-store";

      const apiStore = useApiCallStore();

      onMounted(async () => {
        console.log("🚀 App mounted, checking login state...");
        const success = await apiStore.autoLogin();

        if (!success) {
          console.warn("🚫 AutoLogin failed, redirecting to /login...");
          window.location.href = "/login";
        } else {
          console.log("✅ User restored successfully from token");
        }
      });
      </script>


#### 💡 Dôležité:
- autoLogin() sa musí vykonať ešte pred zobrazením layoutu.
- Cursor môže pridať await logiku v hlavnom App.vue alebo boot/auth.ts,
ak existuje auth boot súbor — nech použije najvhodnejší spôsob.

### 3️⃣ src/router/index.ts (ak existuje redirect)
- Zmeň kontrolu redirectu:

      if (!apiStore.isAuthenticated && !localStorage.getItem("jwtToken")) {
        next("/login");
      } else {
        next();
      }

### 🧪 Testovací scenár

#### ✅ Scenár A – Auto-login po refreši
- Prihlás sa (mato@example.com / secret123)
- Stlač / Urob Ctrl + R (refresh stránky)
- Sleduj konzolu:
  - 🚀 App mounted, checking login state...
  - ✅ User restored successfully from token
- Používateľ ostáva na /donor/posts

#### ✅ Scenár B – Expired token
- Po prihlásení zmeň token na neplatný v LocalStorage
- Stlač / Urob Ctrl + R (refresh stránky)
- Sleduj logy:
  - ⚠️ Token invalid, trying refresh...
  - 🔁 Token refreshed successfully
- Používateľ ostáva prihlásený

#### ✅ Scenár C – Refresh zlyhá
- Poškodný aj refresh token
- Stlač / Urob Ctrl + R (refresh stránky)
- Sleduj:
  - 🚫 Refresh failed
  - Redirect na /login
