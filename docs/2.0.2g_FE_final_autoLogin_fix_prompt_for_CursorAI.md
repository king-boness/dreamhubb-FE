# ✅ Final Fix: Auto-login after refresh (stabilné načítanie tokenu)

## Kontext
Auto-login funguje, ale `App.vue` sa mountuje skôr, než Quasar/PINIA stihne obnoviť `localStorage`.
Výsledkom je falošný redirect na `/login`, hoci token sa o pár stotín sekundy neskôr uloží.

## Cieľ
- Spustiť `autoLogin()` aj na chránených route (/donor, /donee)
- Zaviesť čakaciu slučku, ktorá reálne počká, kým token dorazí
- Odstrániť predčasné redirecty

## Zmeny

### 1️⃣ Súbor `src/App.vue`
Nahraď celý obsah `<script setup lang="ts">` týmto:

    ts

    <script setup lang="ts">
    import { onMounted, ref } from "vue";
    import { useRouter } from "vue-router";
    import { useQuasar } from "quasar";
    import { useApiCallStore } from "src/stores/api-calls-store";

    const $q = useQuasar();
    $q.dark.set(true);

    const router = useRouter();
    const apiStore = useApiCallStore();
    const loginChecked = ref(false);

    onMounted(async () => {
      if (loginChecked.value) return;
      loginChecked.value = true;

      const currentRoute = router.currentRoute.value;
      const routeName = currentRoute.name as string;

      // 🚫 Nepúšťaj autoLogin len na explicitných AUTH stránkach

      const authRoutes = ["login", "registration", "landing", "explainers", "splash"];
      if (authRoutes.includes(routeName)) {
        console.log("🚫 Skipping autoLogin on auth route:", routeName);
        return;
      }

      console.log("🚀 App mounted, waiting for token sync...");

      // 🧭 Reálna kontrola tokenu s 10 pokusmi (max 1 sekunda)

      let token = null;
      for (let i = 0; i < 10; i++) {
        token = localStorage.getItem("jwtToken");
        if (token) break;
        await new Promise((r) => setTimeout(r, 100));
      }

      if (!token) {
        console.warn("⚠️ Token not found after 1s delay, giving one final retry...");
        await new Promise((r) => setTimeout(r, 300));
        token = localStorage.getItem("jwtToken");
      }

      if (!token) {
        console.warn("🚫 No token found after retries, redirecting to /login...");
        router.replace("/login");
        return;
      }

      console.log("🔑 Token found, verifying auto-login...");

      const success = await apiStore.autoLogin();

      if (!success) {
        console.warn("⚠️ Auto-login verification failed, redirecting to /login...");
        router.replace("/login");
      } else {
        console.log("✅ Auto-login verified successfully — user remains logged in");
      }
    });
    </script>
