# 2.0.2 / FE – Refresh token & Auto-login systém

## 🎯 Cieľ
Zabezpečiť, aby sa používateľ **automaticky prihlásil po refreši stránky**,
a aby **FE automaticky obnovoval JWT token**, keď expiruje.
Cieľom je dosiahnuť trvalý prístup k chráneným endpointom bez nutnosti manuálneho loginu.

## 🧭 Kontext
- Framework: Vue 3 + Quasar + Pinia + TypeScript
- API endpointy (Laravel BE):
  - `/api/login`
  - `/api/refresh` – generuje nový access token
  - `/api/logout` – zneplatní aktuálny token
- JWT tokeny sa ukladajú do: `localStorage.jwtToken`
- Axios interceptor sa nachádza v: `/src/boot/axios.ts`
- Aktuálne funguje ručné prihlásenie a pridávanie tokenu do requestov

## ⚙️ Implementácia

### 1️⃣ Úprava `src/boot/axios.ts`
- Pridať **globálny interceptor pre odpovede (response interceptor)**
  → Ak backend vráti `401 Unauthorized`, automaticky sa spustí request na `/refresh`.
- Po získaní nového tokenu:
  - uložiť ho do `localStorage`
  - aktualizovať `Authorization` header pre ďalšie requesty
  - retry pôvodný request
- Ak `refresh` zlyhá (napr. expiroval aj refresh token):
  - odstrániť token z `localStorage`
  - presmerovať používateľa na `/login`

### 2️⃣ Úprava `src/stores/api-call-store.ts`
- Pridať **nové metódy:**
  - `autoLogin()` → overí, či existuje platný token, a otestuje ho (napr. volaním `/posts`)
  - `logout()` → odstráni token z localStorage a volá `/logout`
- Funkcia `autoLogin()` sa bude volať:
  - pri štarte aplikácie (`onMounted` v `App.vue`)
  - pri každom refreši stránky

### 3️⃣ Úprava `App.vue`
- Po spustení aplikácie:

      ts

      import { useApiCallStore } from "src/stores/api-call-store";
      const apiStore = useApiCallStore();
      apiStore.autoLogin();

- Ak token nie je platný → redirect na /login
- Ak token platí → pokračovať na aktuálnu stránku

### 4️⃣ Testovanie

#### ✅ Scenár A – Refresh token po expiracii
- Prihlás sa (/login)
- Ručne nastav v localStorage.jwtToken neplatný token
- Otvor stránku /donor/posts
- Sleduj Console (DevTools):
  - ⚠️ Token expired, attempting refresh...
  - ✅ Token successfully refreshed
  - GET /posts returned 200

#### ✅ Scenár B – Auto-login po refreši
- Po prihlásení refreshni stránku (F5)
- Očakávaj log:
  - 🔁 Auto-login successful – token valid
- Endpoint /posts by sa mal načítať bez nutnosti opätovného loginu

#### ✅ Scenár C – Logout
- Klikni „Logout“ alebo volaj apiStore.logout()
- Sleduj log:
  - 👋 User logged out, token cleared
- Po refreši ťa FE presmeruje na /login

### 🧠 Očakávaný výsledok
- FE po načítaní automaticky rozpozná, či má platný token
- Ak token expiroval, FE automaticky zavolá /refresh
- Ak refresh prejde, token sa uloží a FE pokračuje bez výpadku
- Ak refresh zlyhá → redirect na /login
- Používateľ zostáva prihlásený aj po refreši stránky
