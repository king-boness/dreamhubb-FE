# 🧩 Fine-tuning: autoLogin delay timing (token sa uloží o pár ms neskôr)

## Kontext
Po aplikácii `2.0.2d` fixu je autoLogin funkčný, ale logy ukazujú, že kontrola prebehne
**o niekoľko milisekúnd predtým**, ako sa JWT stihne uložiť do localStorage.

## Cieľ
Doladiť načasovanie a zaručiť, že `App.vue` čaká, kým je JWT token skutočne prítomný
v `localStorage` (aj ak sa načíta s miernym oneskorením po logine).

## Zmeny

### 1️⃣ `src/App.vue`
Nahradiť aktuálne:

    ts

    await new Promise(resolve => setTimeout(resolve, 200));
    const token = localStorage.getItem("jwtToken");

za tento presnejší variant:

    // 🧭 Čakaj až do 1 sekundy, kým sa token objaví

    let token = null;
    for (let i = 0; i < 10; i++) {
      token = localStorage.getItem("jwtToken");
      if (token) break;
      await new Promise(r => setTimeout(r, 100)); // každých 100 ms skontroluj znova
    }

    if (!token) {
      console.warn("⚠️ Token not found after 1s, redirecting to /login...");
      router.replace("/login");
      return;
    }

### 2️⃣ Logy

Vylepšiť výstup:

    console.log("🔍 Token found after", i * 100, "ms, verifying auto-login...");

### Test
1. Spusť FE (npm run dev)
2. Prihlás sa
3. Stlač Ctrl + R
4. Očakávané logy:

        🚀 App mounted, waiting for token sync...
        🔍 Token found after 200 ms, verifying auto-login...
        ✅ Auto-login verified successfully

Bez redirectu na /login ✅
