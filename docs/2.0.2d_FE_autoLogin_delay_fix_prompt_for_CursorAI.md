# ⚙️ Fix: Auto-login prebieha skôr, než je JWT token načítaný (časovanie / race condition)

## 🧭 Kontext
Po aplikovaní `2.0.2c` fixu prestal FE padať do nekonečného loopu ✅,
ale po refreši stránky (`Ctrl + R`) sa zobrazuje log:

    ⚠️ No token found, skipping autoLogin
    🚫 AutoLogin failed, redirecting to /login (once)...

aj keď token je v `localStorage` (viditeľný po pár ms).


## 🎯 Cieľ
Zabezpečiť, aby sa `autoLogin()` spúšťal **až po načítaní localStorage**
a aby FE neodhlásil používateľa, ak token už existuje, len ešte nebol načítaný.

## ⚙️ Požadované opravy (Cursor vykoná)

### 1️⃣ `src/App.vue`

➡️ Pridaj malú oneskorenú inicializáciu `autoLogin()` (100–300ms), aby store stihol získať token.

➡️ Pridaj extra kontrolu: ak token existuje v localStorage, nespúšťaj redirect hneď.

    ts
    <script setup lang="ts">
    import { onMounted, ref } from "vue";
    import { useRouter } from "vue-router";
    import { useApiCallStore } from "src/stores/api-call-store";

    const router = useRouter();
    const apiStore = useApiCallStore();
    const loginChecked = ref(false);

    onMounted(async () => {
      if (loginChecked.value) return;
      loginChecked.value = true;

      console.log("🚀 App mounted, waiting for token sync...");
      await new Promise(resolve => setTimeout(resolve, 200)); // ⏳ počkaj na localStorage sync

      const token = localStorage.getItem("jwtToken");
      if (!token) {
        console.warn("⚠️ No token found after delay, redirecting to /login...");
        router.replace("/login");
        return;
      }

      console.log("🔑 Token found, verifying auto-login...");
      const success = await apiStore.autoLogin();

      if (!success) {
        console.warn("🚫 AutoLogin verification failed, redirecting to /login...");
        router.replace("/login");
      } else {
        console.log("✅ Auto-login verified successfully");
      }
    });
    </script>

### 2️⃣ src/stores/api-call-store.ts

➡️ Pridaj logiku pre „delayed“ token attach (len ak chýba).

➡️ Uisti sa, že autoLogin() neprebieha paralelne s iným requestom.

    ts

    async autoLogin() {
      const token = localStorage.getItem("jwtToken");
      if (!token) {
        this.isAuthenticated = false;
        console.warn("⚠️ AutoLogin aborted – no token in localStorage.");
        return false;
      }

      try {
        const res = await api.get("/posts");
        if (res.status === 200) {
          this.isAuthenticated = true;
          console.log("✅ Auto-login successful – token verified via /posts");
          return true;
        }
      } catch (err) {
        console.warn("⚠️ Auto-login token invalid:", err.message);
        this.isAuthenticated = false;
        return false;
      }
    }

### 🧪 Testovací scenár

#### ✅ Scenár A – Po refreši

      ⚠️ No token found after delay, redirecting to /login...

#### ✅ Scenár C – Zlý token
- Poškodz token v localStorage
- Spusti aplikáciu → redirect na /login po neúspešnej verifikácii
- Console:
