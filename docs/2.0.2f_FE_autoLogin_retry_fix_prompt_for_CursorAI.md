# 🧩 Fix: Retry autoLogin pred redirectom (token sa načíta tesne po kontrole)

## Kontext
Po fixoch 2.0.2d a 2.0.2e FE funguje stabilne, no pri refreši stránky
sa `App.vue` niekedy pokúsi o autoLogin skôr, než je token uložený do localStorage.
Výsledkom je predčasný redirect na `/login`, aj keď token sa objaví o pár stotín sekundy neskôr.

## 🎯 Cieľ
Zaviesť **“retry kontrolu”** — ak token nie je prítomný v prvej kontrole, FE má
pred redirectom urobiť ešte **druhý pokus o overenie** po krátkom čase (napr. 500 ms).

## 🔧 Úpravy

### 1️⃣ Súbor `src/App.vue`
V časti `onMounted` aktualizuj logiku čítania tokenu nasledovne:

    ts

    onMounted(async () => {
      console.log("🚀 App mounted, waiting for token sync...");

      let token = null;
      for (let i = 0; i < 10; i++) {
        token = localStorage.getItem("jwtToken");
        if (token) break;
        await new Promise(r => setTimeout(r, 100));
      }

      // 🟠 Ak token stále neexistuje, sprav jeden retry po 500ms

      if (!token) {
        console.warn("⚠️ Token not found after initial delay, retrying autoLogin in 500ms...");
        await new Promise(r => setTimeout(r, 500));
        token = localStorage.getItem("jwtToken");
      }

      if (!token) {
        console.warn("🚫 No token found after retry, redirecting to /login...");
        router.replace("/login");
        return;
      }

      console.log("🔑 Token found, verifying auto-login...");
      const success = await apiStore.autoLogin();

      if (!success) {
        console.warn("⚠️ Auto-login verification failed, redirecting to /login...");
        router.replace("/login");
      } else {
        console.log("✅ Auto-login verified successfully");
      }
    });
