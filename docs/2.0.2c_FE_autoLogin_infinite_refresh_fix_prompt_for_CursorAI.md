# 🩹 Bugfix: Nekonečný refresh po `npm run dev` (auto-login loop)

## 🧭 Kontext
Po aplikácii `2.0.2b` fixu sa aplikácia po spustení (`npm run dev`) neustále refreshuje.
Príčinou je nekonečná slučka medzi `App.vue` → `autoLogin()` → `window.location.href = "/login"`
ktorá sa opakuje pri každom mountnutí aplikácie.

## 🎯 Cieľ
Zabrániť opakovanému re-renderu a refreshu stránky.
Aplikácia má po štarte:
- raz zavolať `autoLogin()`,
- ak token existuje a je platný → ostať prihlásený,
- ak token neexistuje → **presmerovať na `/login` len raz**, bez nekonečného loopu.

## ⚙️ Požadované opravy

### 1️⃣ `src/App.vue`

➡️ Nahradiť `window.location.href = "/login"` za routerový redirect, ktorý sa spustí len raz.

➡️ Pridať guard premennú, aby sa `autoLogin()` nespúšťal opakovane.

    ts

    <script setup lang="ts">
    import { onMounted, ref } from "vue";
    import { useRouter } from "vue-router";
    import { useApiCallStore } from "src/stores/api-call-store";

    const router = useRouter();
    const apiStore = useApiCallStore();
    const loginChecked = ref(false);

    onMounted(async () => {
      if (loginChecked.value) return; // 🔒 Zabráni opakovanému spusteniu
      loginChecked.value = true;

      console.log("🚀 App mounted, checking login state...");
      const success = await apiStore.autoLogin();

      if (!success) {
        console.warn("🚫 AutoLogin failed, redirecting to /login (once)...");
        router.replace("/login"); // 🧭 bez window.location.href
      } else {
        console.log("✅ User restored successfully from token");
      }
    });
    </script>

### 2️⃣ src/stores/api-call-store.ts

➡️ Uisti sa, že autoLogin() nevyvoláva zbytočné refreshy.

➡️ Pridaj návratovú hodnotu (true/false) podľa výsledku,
aby App.vue vedel rozlíšiť, či redirectovať.

    ts

    async autoLogin() {
      const token = localStorage.getItem("jwtToken");
      if (!token) {
        this.isAuthenticated = false;
        return false;
      }

      try {
        const res = await api.get("/posts");
        if (res.status === 200) {
          this.isAuthenticated = true;
          console.log("✅ Auto-login successful – token valid");
          return true;
        }
      } catch (err) {
        console.warn("⚠️ Auto-login check failed:", err.message);
        this.isAuthenticated = false;
        return false;
      }
    }

### 3️⃣ (Voliteľné) src/router/index.ts

➡️ Cursor môže pridať jednoduchý guard, ktorý zabezpečí, že /login sa nespustí donekonečna:

    ts

    router.beforeEach((to, from, next) => {
      const token = localStorage.getItem("jwtToken");

      if (to.path === "/login" && token) {
        // 🧠 Už prihlásený používateľ → nech ho presmeruje napr. na /donor/posts
        next("/donor/posts");
      } else {
        next();
      }
    });
