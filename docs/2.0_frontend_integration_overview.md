# 🧩 2.0 / Frontend – Integrácia s Backend-om (štart FE)

---

## 🎯 Hlavný cieľ sekcie

Prepojiť **frontend aplikáciu dreamhubb (Vue + Quasar + Pinia)** s backendom (Laravel API) tak,
aby sa dosiahlo **kompletné spracovanie autentifikácie, profilových dát, postov a uploadov**
v reálnom čase medzi FE a BE.

---

## ⚙️ Technologický kontext

| Vrstva | Použitá technológia | Stav |
|--------|--------------------|------|
| Backend | Laravel 11 + PostgreSQL + JWTAuth | ✅ Hotové |
| Frontend | Vue 3 + Quasar Framework + Pinia | 🟢 Aktívny vývoj |
| Komunikácia | Axios + REST API (`http://127.0.0.1:8000/api`) | 🟢 Prebieha |
| Ukladanie tokenu | LocalStorage (`jwtToken`) | ✅ Funkčné |
| Hostingové prostredie | Render (BE), Netlify (FE – budúce) | ⏳ Po integrácii |

## 🧠 Kontext pre vývoj

Sekcia **2.0** je mostom medzi backendom a frontend UX, kde sa buduje:
- logika dátových tokov (**API ↔ Pinia store ↔ komponenty**),
- bezpečné spracovanie tokenov (**login, refresh, logout**),
- a “živé” zobrazovanie príspevkov, používateľov a obrázkov.

Po jej uzavretí bude aplikácia **plne funkčná na lokálnom prostredí**,
pripravená na fázu **3.0 – UX polish, staging a build do mobilu.**
